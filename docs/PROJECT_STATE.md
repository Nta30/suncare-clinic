## 9. Quyết định kỹ thuật

- Frontend và backend tách riêng.
- Backend sử dụng Modular Monolith.
- Database sử dụng SQL Server.
- Flyway quản lý schema migration.
- Không sử dụng Hibernate ddl-auto để tạo/sửa schema.
- Thời gian lưu UTC.
- Tiền sử dụng decimal.
- Tuân thủ D01-D23 và T01-T10.
- Không tự ý sửa thiết kế database.
